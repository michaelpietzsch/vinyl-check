# vinyl-check

Measure the condition of vinyl records with the turntable you already have: click and pop detection,
condition grading, before/after comparison of record cleaning, turntable calibration with a test record,
comparison against the digital master and test pressing approval.

Works with a simple USB turntable as well as with a high-end turntable and audio interface, as long as the
setup guide is followed.

The source code is being prepared for its first public release.
